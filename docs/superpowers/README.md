# Development notes

Specs, plans and journals written while this Android version was being built, kept as a record of how it was made. The plans and specs are in Spanish; the journals are in English.

They are a history, not documentation of the current app:

- They describe steps and parts that no longer exist, such as the Windows backend, .NET and DuckStation.
- Notes about licensing and permission describe the state at the time they were written. The current terms are in [`LICENSE`](../../LICENSE) and [`NOTICE`](../../NOTICE): GPL-3.0-or-later, with Jean Carlos Heck's permission for the inherited code.
- Many steps are written as instructions for the coding agents that helped build the app, and "the owner" is the author of this version.
- Disc dumps, RAM dumps and reference outputs mentioned in them stay outside the repository.

For how to build and use the app, see the [README](../../README.md) and the [Android technical guide](../../Android/README.md).
